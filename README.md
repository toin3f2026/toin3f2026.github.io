# 整理券オーダーシステム（toin3f2026）

飲食店向けの、整理券番号ベースの注文管理・呼び出しWebアプリです。
PC・スマートフォン（iOS / Android）に対応しており、単一のHTMLファイルだけで動作します。

> **この、リポジトリのソースコードは、Anthropic社のAIアシスタント「Claude」の支援を受けて作成されました。**
> The source code in this repository was written with the assistance of Claude, an AI assistant by Anthropic.

---

## できること

- **客側画面**：整理券番号を入力すると、以下の4状態のいずれかと（お作り中の場合は）自分の前に待っている人数を表示
  1. 不明な番号です
  2. お作り中です
  3. 受け取り可能です
  4. 受け渡し済みです
- **店側注文管理画面**（パスワード保護）：Excelのような表形式で、整理券番号ごとの商品数・合計金額・注文日時・完成／受渡し状況を管理。複数シートを作成し、客側に反映するシートを選択可能
- **店頭表示用画面**：受け取り可能な整理券番号を大きく表示
- **厨房表示用画面**：お作りするべき料理の個数を大きく表示
- 客側画面・店頭表示画面は、夜空とランタンをテーマにしたオリジナルデザイン
- Firebase Realtime Databaseを使用し、複数端末（お客様のスマホ・カウンター・厨房・店頭ディスプレイ）でリアルタイムにデータを共有
- 客側画面・パスワード画面は、3分間操作がないと自動的にサーバー接続を切断し、データベースの無駄な接続を防止

## セットアップ手順

このアプリはデータの保存にFirebase Realtime Databaseを使用します。利用する前に、以下の設定が必要です。

### 1. Firebaseプロジェクトを作成する

1. [Firebaseコンソール](https://console.firebase.google.com/) でプロジェクトを新規作成
2. 「構築」→「Realtime Database」→「データベースを作成」
3. プロジェクトの設定 →「マイアプリ」からウェブアプリを追加し、`firebaseConfig` の値を取得

### 2. `firebaseConfig` を書き換える

`index.html`（または本ファイルと同名のHTMLファイル）内、`<script>` タグの冒頭付近にある以下の部分を、自分のFirebaseプロジェクトの値に書き換えてください。

```js
const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  databaseURL: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
```

### 3. Realtime Databaseのセキュリティルールを設定する

Realtime Databaseの「ルール」タブで、以下のように設定してください（「テストモード」のままだと数週間で自動的に読み書き不可になります）。

```json
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
```

> ⚠️ このルールは誰でも読み書きできる設定です。データベースのURLを知っている第三者からもアクセスできてしまう点にご注意ください。

### 4. 管理画面パスワードを変更する

`index.html` 内の以下の行を、任意のパスワードに書き換えてください。

```js
const ADMIN_PASSWORD = '3f2026';
```

### 5. GitHub Pagesで公開する

1. このリポジトリのファイル（HTMLファイルなど）をアップロード
2. ファイル名を `index.html` にしておくと、公開URLがそのままトップページになります
3. リポジトリの「Settings」→「Pages」→ ソースを対象ブランチ・ルートフォルダに設定して保存
4. `https://（ユーザー名）.github.io/（リポジトリ名）/` で公開されます

## 注意事項

- Firebaseの無料枠（Sparkプラン／Realtime Database）には、同時接続数100・月間ダウンロード量10GBなどの上限があります。大規模なイベントで多数のアクセスが見込まれる場合は、Blazeプラン（従量課金）への切り替えをご検討ください。
- 個人情報（氏名・連絡先等）は一切取得していません。整理券番号と注文内容のみを扱います。
- 本アプリの動作や表示内容について、通信状況やシステム障害により実際の状況と異なる場合があります。正式な状況はカウンターにてご確認ください。
